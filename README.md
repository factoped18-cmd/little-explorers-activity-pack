# Facto Printables — Little Explorers Animal Activity Pack

A responsive landing page for **Facto Printables**, featuring *Little Explorers: Animal Activity Pack*, a printable animal-themed activity PDF for children ages 3–5.

The page introduces the product, explains what families can expect, and directs customers to Payhip checkout.

## Product Details

- **Public website brand:** Facto Printables
- **Product:** Little Explorers: Animal Activity Pack
- **Format:** Digital PDF
- **Age range:** 3–5 years
- **Activities:** 10 animal-themed activities, including matching, counting, patterns, tracing, drawing, and observation
- **Price displayed:** ₹21
- **Delivery:** Payhip handles digital delivery after successful purchase

## Features

- Responsive layout for desktop and mobile
- Green, cream, and orange visual theme
- Animal-themed cover artwork embedded in the HTML
- Sticky navigation with active-section highlighting
- Mobile navigation menu
- Product overview and activity highlights
- Contact section with clickable support email
- Privacy, terms, refund/cancellation, and digital-delivery information
- Purchase buttons linked to Payhip checkout

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

No frontend framework or build step is required.

## Run Locally

Open `index.html` in a web browser.

## Deploy with GitHub Pages

1. Upload `index.html` to the root of the repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`.
5. Save and wait for deployment to complete.
