# Facto Printables — Little Explorers Animal Activity Pack

A responsive landing page for **Facto Printables**, featuring *Little Explorers: Animal Activity Pack*, a printable animal-themed activity PDF for children ages 3–5.

The page introduces the product, explains what families can expect, and directs customers to Payhip checkout.

## Product Details

- **Public website brand:** Facto Printables
- **Product:** Little Explorers: Animal Activity Pack
- **Format:** Digital PDF
- **Age range:** 3–5 years
- **Activities:** 10 animal-themed activities, including matching, counting, patterns, tracing, drawing, and observation
- **Price displayed:** ₹21
